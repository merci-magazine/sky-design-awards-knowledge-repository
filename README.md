# Sky Design Awards Knowledge Repository

Public project records for **Sky Design Awards by Merci Magazine**.

Design, People, Cities and Art.

## 2026 project records

- [Browse the 88 shortlisted projects](Shortlisted/2026.md).
- [Read the machine-readable project dataset](data/2026/projects.json).

The 2026 collection contains SKR-2026-000001 through SKR-2026-000088. Every record includes project metadata, an excerpt, the current main editorial and retained official links. These records identify shortlisted/finalist projects; no winner outcomes are announced by this release.

## Scope and provenance

The project text was prepared from the latest editorial documents confirmed by Merci Magazine on 28 October 2026. Existing company and Merci Magazine project links are retained from its established project registry. SKR numbers serve as stable record identifiers. Established SDA entry numbers retain their registry suffixes and formatting.

This public edition contains the main project articles. Internal verification notes, editorial working notes, original application appendices, private Drive links and source-contact fields are omitted. The main editorial wording is preserved. Embedded images, drawings, Google Docs formatting and revision history are not included. Links to official project and company pages provide further context; their contents may change independently.

## Search and access

The Markdown records and JSON dataset can be read without signing in when this repository is public. Public accessibility does not guarantee that any search engine or AI service will index, retrieve or cite a record, nor does it imply inclusion in model training.
